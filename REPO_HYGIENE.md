# Repo Hygiene — Public Standards (v1)

## Audit Checklist
- Archive or de‑emphasize anything off‑brand
- Add context README to every experiment
- Reframe repos as primitives or probes
- Standardize descriptions across repos

## Description Template (1 line)
`Primitive/Probe: <system-level framing>. Status: <active|experimental|archived>.`

## README Template (short)
- **Question**: What is being tested?
- **Primitive**: What system building block is isolated?
- **Why it matters**: Why this matters at scale?
- **Status**: Active / Experimental / Archived
- **Notes**: constraints, guardrails, or limitations
